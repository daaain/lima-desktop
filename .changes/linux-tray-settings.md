- **On Linux, Settings offers each menu bar item's drawing only.** Most panels show a tray item's image alone (its label only with GNOME's AppIndicator extension), so the figure and the names never showed there, and an item set to show only its figure appeared as the app's icon. Now there's no figure or name to choose on Linux, and an item drawn as None is left out of the panel.
